### Sobre mim ♥

</div>

Sou estudante de **Ciência da Computação** e entusiasta do universo da tecnologia. Por aqui, compartilho um pouco dessa jornada: projetos, experimentos, aprendizados e ideias que aos poucos ganham forma através do código. ✨

Atualmente, meus estudos estão focados em:
* Backend com Java e Spring Boot
* Construção de APIs REST
* Containerização de aplicações com Docker
* Testes Unitários com Junit e Mockito
* Versionamento de banco de dados com Flyway
* Persistência de dados
* Modelagem e Arquitetura de Software

Busco aprimorar meus conhecimentos, explorar novas tecnologias e desenvolver uma visão cada vez mais completa sobre engenharia de software.
